Agentforce in Slack

Three agents with specific jobs.

Not "AI everywhere." Each agent has a trigger, a decision it makes and an action it takes, and a person can approve or override every step.

Deal Agent

Trigger
Something that sounds like a stage change is posted in a deal channel
Decides
Whether the stage's exit criteria are met and which fields need updating
Acts
Suggests the record update inline. It writes to Salesforce once the owner confirms

Answer Agent

Trigger
A prospect question or RFP item is posted in a channel
Decides
Whether an approved answer already exists in Slack threads, docs or past RFPs
Acts
Drafts a sourced answer, or sends it to the right SME with context attached

Renewal Prep Agent

Trigger
90 days before a customer renewal date
Decides
Which usage, support and relationship signals are relevant
Acts
Opens a renewal channel with a briefing and a draft agenda for the account team
